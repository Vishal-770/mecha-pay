## Installation

Install the SDK using your favorite package manager:

```bash
npm install mechapay-sdk
# or
yarn add mechapay-sdk
# or
pnpm add mechapay-sdk
```

## Configuration

To use the SDK, you must wrap your application (usually in `App.tsx` or `main.tsx`) with the `MechaProvider`. This component provides the necessary context for all other SDK components and hooks.

```tsx
import { MechaProvider } from 'mechapay-sdk';

function App() {
  return (
    <MechaProvider 
      apiKey="mp_live_..." 
      portalUrl="https://mecha-pay.vercel.app"
    >
      <MyRoutes />
    </MechaProvider>
  );
}
```

### Provider Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| `apiKey` | `string` | Your Mecha Pay Developer API Key. |
| `portalUrl` | `string` | The URL of the Mecha Pay dashboard (e.g., `https://mecha-pay.vercel.app`). |
| `theme` | `object` | (Optional) Custom theme configuration for UI components. |
