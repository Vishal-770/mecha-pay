Mecha Pay is a fully decentralized subscription protocol. Our Developer API provides programmatic access to your merchant data, plans, and subscriber analytics.

## Getting Started

To get started with the API:
1. Navigate to your [Developer Dashboard](http://localhost:3000/dashboard/developer).
2. Generate an API Key.
3. Authenticate your requests using the `x-api-key` header.

## API Architecture

The Mecha Pay API is RESTful and built around standard HTTP methods. All endpoints are scoped to your merchant account and data.
